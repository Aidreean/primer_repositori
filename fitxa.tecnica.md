# Fitxa tècnica: Instal·lació de Kea DHCP

## Objectiu

Explicar la instal·lació i configuració bàsica del servidor Kea DHCP.

## Materials

- Ubuntu Server
- Accés a Internet
- Visual Studio Code

## Procediment

1. Actualitzar el sistema.
2. Instal·lar Kea DHCP.
3. Configurar el fitxer de Kea.
4. Reiniciar el servei.
5. Comprovar el funcionament.

## Comprovacions

- [ ] Servei actiu
- [ ] Adreces IP assignades correctament

## Incidències i solucions

| Incidència | Solució |
|---|---|
| El servei no arrenca | Revisar configuració |
| No reparteix IPs | Comprovar la subxarxa |
